# EclesiaPresenter

![Latest release](https://img.shields.io/github/v/release/Juanalejo01/eclesia-presenter?label=versi%C3%B3n&color=a85f33)
![Platform](https://img.shields.io/badge/plataforma-Windows%20%7C%20macOS%20%7C%20Android-1c1614)

**Software de presentación para iglesias** — Biblia, canciones, lista del día, proyección para OBS y mando a distancia desde el móvil.

## Descargas

| Plataforma | Descarga |
|---|---|
| Windows (instalador) | [EclesiaPresenter-setup.exe](https://github.com/Juanalejo01/eclesia-presenter/releases/latest) |
| Windows (portable, sin instalación) | [EclesiaPresenter-portable.exe](https://github.com/Juanalejo01/eclesia-presenter/releases/latest) |
| macOS (Apple Silicon) | [EclesiaPresenter-arm64.zip](https://github.com/Juanalejo01/eclesia-presenter/releases/latest) |
| Android (mando móvil, APK) | [Releases `mobile-v*`](https://github.com/Juanalejo01/eclesia-presenter/releases?q=mobile&expanded=true) |

La versión de escritorio incluye **actualizaciones automáticas**: la app avisa cuando hay una versión nueva y se actualiza sola.

## Características

- 📖 **Biblia** — 10 versiones en español (RVR1960, RV2020, NVI, NTV, DHH, LBLA, TLA y más), búsqueda por referencia (`Juan 3:16`, `salmos 22 1-5`) o por texto.
- 🎵 **Canciones** — biblioteca con secciones (verso/coro/puente), importación desde Holyrics, búsqueda instantánea.
- 📋 **Lista del día** — organiza el orden del servicio y proyecta con un clic.
- 🖥️ **Proyección** — pantalla secundaria o overlay transparente para OBS (Browser Source).
- 📱 **Mando móvil** — controla la proyección desde el teléfono (PWA en red local o APK Android), con emparejamiento por PIN.
- 🌐 **Multi-idioma** — Español, English, Português.
